# Doubao-ContextMenu-Cleaner

> ️ **重要安全提示**
> 修改注册表存在一定风险，**请务必在运行前仔细阅读脚本内容**。脚本中已包含自动备份机制，但为了绝对安全，建议你在运行前手动导出注册表备份，或创建一个系统还原点。

##  清理脚本代码
请将以下代码复制到记事本中，并**另存为** `CleanDoubao.bat`（注意：保存类型请选择“所有文件”，编码建议选择“ANSI”以防止中文乱码）。

## ️ 使用方法
1. 找到你保存的 `CleanDoubao.bat` 文件。
2. **右键**点击该文件，选择“**以管理员身份运行**”（脚本也会自动尝试提权）。
3. 等待脚本运行完毕，它会提示“清理完成”。
4. 此时资源管理器会自动重启，你可以右键任意文件查看“打开方式”，豆包浏览器的残留选项应该已经彻底消失了。

##  恢复说明
如果清理后发现误删了其他正常软件的关联，你可以去桌面上找到名为 `Doubao_Reg_Backup_日期` 的文件夹，里面保存了清理前的注册表备份，双击里面的 `.reg` 文件即可一键恢复。
